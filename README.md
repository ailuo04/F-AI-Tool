# F-AI Tool

F-AI Tool 是一款 Windows 工具，可管理自定义模型提供商，并通过本地网关将模型接入 ChatGPT/Codex。

## 下载

**[下载 F-AI Tool v1.0.0 Windows 安装包](https://github.com/ailuo04/F-AI-Tool/releases/download/v1.0.0/F-AI-Tool-1.0.0-setup.exe)**

[查看 v1.0.0 发布说明](https://github.com/ailuo04/F-AI-Tool/releases/tag/v1.0.0)

安装包适用于 Windows x64。当前为未签名预览版，Windows 可能显示“未知发布者”。

## 开始使用

1. 运行安装包并打开 F-AI Tool。
2. 在「提供商」填写服务地址、API Key 和要使用的模型。
3. 按需在「模型」中启用注入，然后重启 ChatGPT 客户端。
