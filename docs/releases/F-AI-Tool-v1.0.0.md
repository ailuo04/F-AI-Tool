## F-AI Tool v1.0.0

### 本次更新

- F-AI Tool 公开版从 `v1.0.0` 开始独立编号。应用和安装包使用 f-api.site 的图标。
- 可添加自己的模型提供商、API Key 和模型，默认本地网关为 `127.0.0.1:18121`。
- 公开版拥有独立的安装身份、配置目录和更新源。如果 Windows 账号已有自用版配置，请在独立 Windows 账号或虚拟机运行公开版。

### 安装

下载下方的 `F-AI-Tool-1.0.0-setup.exe`，在 Windows x64 上运行。安装以当前用户身份进行。

本安装包未签名，Windows 可能显示“未知发布者”。如已安装此前的 `v1.7.10` 预览版，请手动运行本安装包切换到 `v1.0.0`。
